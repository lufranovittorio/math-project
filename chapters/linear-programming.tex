\chapter{Linear Programming}\label{linear-programming}
\chapterstatus{planned}

Optimising a linear function over a polyhedron: the geometry of polyhedra, the simplex method and
duality.

\noindent\textbf{Prerequisites.} Chapter~\ref{convex-analysis} (Convex Analysis).

\noindent\textbf{Planned contents.}
\begin{enumerate}
\item Polyhedra, vertices, the Minkowski--Weyl theorem.
\item Farkas' lemma revisited; strong duality and complementary slackness.
\item The simplex method, degeneracy, Bland's rule.
\item Integrality: totally unimodular matrices, network flows.
\item Interior point methods and the ellipsoid method (introduction).
\item Exercises with solutions.
\end{enumerate}
